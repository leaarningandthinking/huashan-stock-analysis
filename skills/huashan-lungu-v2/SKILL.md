# 华山论股 V2

## 何时使用

满足任一条件即使用：
- 用户上传券商 App 持仓截图或粘贴持仓清单
- 用户要求“用 XX 大师视角分析”
- 用户要求“让 XX 和 XX 辩论”
- 用户消息包含 `【分析风格：XX式】`
- 用户提到“华山论股 / 持仓分析 / 大师辩论 / 多空论股”

不用于：
- 单股短线价格预测
- 不涉及具体持仓的纯理论讨论

## 模式

- 独门论股：选择 1 位大师，做深度诊断和多空自辩
- 群雄论股：选择 2-3 位大师，分多空阵营辩论，再由风控团队审核

## 执行流程

1. 识别持仓、用户目标和大师选择
2. 由基本面、情绪、新闻、技术四类分析师整理事实
3. 生成结构化中间报告
4. 按独门论股或群雄论股模式组织大师分析与辩论
5. 由激进、中性、保守三类风控视角复核
6. 输出持仓诊断、主要分歧、风险点和操作纪律

## 输出要求

- 聚焦组合仓位、风险暴露、基本面质量、市场情绪、新闻影响和技术趋势
- 允许呈现明确分歧，不强行调和多空观点
- 不给具体买入价、卖出价、止损价
- 不预测次日或次周涨跌
- 不做单股精准估值
- 结尾必须声明：本分析仅供参考，不构成任何投资建议
