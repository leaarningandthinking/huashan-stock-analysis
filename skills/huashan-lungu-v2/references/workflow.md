# 华山论股 V2 完整工作流程

> 从用户输入到最终输出的完整执行流程。
> 每一步都有明确的输入、处理、输出。

---

## 整体流程图

```
用户输入持仓
    ↓
【Step 1】解析持仓
    ↓
【Step 2】分析师团队（4角色并行）
    ↓
【Step 3】结构化报告生成
    ↓
【Step 4】大师辩论
    ↓
【Step 5】风控团队审核
    ↓
【Step 6】最终报告输出
```

---

## Step 1 · 解析用户输入

### 输入形态

**A. 截图输入（图片）**
- 用视觉能力识别表格结构
- 重点提取：股票名称/代码、当前价、持仓数量、市值、持仓占比、浮动盈亏

**B. 文字粘贴**
- 解析常见格式：制表符分隔、空格对齐、中英文字段名
- 如果字段含义不清，主动询问用户

**C. 表格输入（Markdown/CSV）**
- 直接按表头解析

### 输出：持仓概览

```
## 🎯 持仓概览

- 持仓数量：X只
- 集中度：前3大持仓占比 X%
- 行业分布：行业A X% / 行业B X% / ...
- 整体盈亏：浮盈/浮亏 X%
- 市场分布：A股/港股/美股
```

---

## Step 2 · 分析师团队（4角色并行）

### 2.1 基本面分析师

**任务**：分析持仓股票的基本面数据

**数据来源**：
- 财务报表（季报/年报）
- 估值指标（PE/PB/PS）
- 盈利能力（ROE/ROA/毛利率/净利率）
- 现金流（经营性现金流/自由现金流）
- 负债情况（资产负债率/有息负债）

**输出格式**：
```json
{
  "analyst": "基本面分析师",
  "stocks": [
    {
      "name": "贵州茅台",
      "pe": 30,
      "pb": 8,
      "roe": 32,
      "fcf": "500亿",
      "debt_ratio": "20%",
      "summary": "高ROE、充沛现金流、低负债"
    }
  ]
}
```

### 2.2 情绪分析师

**任务**：分析社交媒体情绪和讨论热度

**数据来源**：
- 雪球/东方财富股吧/同花顺社区
- 情绪评分（-1到+1）
- 讨论热度变化
- 机构持仓变化

**输出格式**：
```json
{
  "analyst": "情绪分析师",
  "stocks": [
    {
      "name": "贵州茅台",
      "sentiment_score": 0.6,
      "sentiment_trend": "偏乐观",
      "discussion_heat": "+15%",
      "institutional_change": "增持"
    }
  ]
}
```

### 2.3 新闻分析师

**任务**：分析近期新闻、公告、行业动态

**数据来源**：
- 公司公告
- 财经新闻
- 行业研报
- 宏观政策

**输出格式**：
```json
{
  "analyst": "新闻分析师",
  "stocks": [
    {
      "name": "贵州茅台",
      "recent_news": ["提价预期", "消费复苏"],
      "industry_trend": "白酒行业回暖",
      "policy_impact": "中性"
    }
  ]
}
```

### 2.4 技术分析师

**任务**：分析技术指标和趋势

**数据来源**：
- 价格走势（日线/周线/月线）
- 技术指标（MACD/RSI/KDJ/均线）
- 成交量变化
- 支撑阻力位

**输出格式**：
```json
{
  "analyst": "技术分析师",
  "stocks": [
    {
      "name": "贵州茅台",
      "trend": "上升趋势",
      "macd": "金叉",
      "rsi": 65,
      "volume_trend": "放量",
      "support": 1500,
      "resistance": 1800
    }
  ]
}
```

```json
    "concentration": "70%",

  "analysis": {
    "fundamentals": [...],
    "sentiment": [...],
    "news": [...],
    "technical": [...]
  },
  "timestamp": "2024-01-15"
}
```

## Step 4 · 大师辩论

### 4.1 独门论股（单大师）

**流程**：
1. 大师查询结构化报告
2. 大师内部多空自辩
3. 输出最终判断

**输出结构**：
```
## 🥋 [大师名字]·独门论股

### 推理过程（ReAct）
[思考 → 行动 → 观察 → 判断]

### 多空自辩
**看多理由**：...
**看空理由**：...

### 最终判断
...

### 逐股审视
[针对持仓中2-4只最值得关注的标的]
```

### 4.2 群雄论股（2-3位大师）

**流程**：
1. 识别大师阵营（看多派/看空派）
2. 大师查询结构化报告
3. 多空阵营对抗辩论
4. 主持人总结

**输出结构**：
```
## 🎙️ 华山论股·群雄对决

### 阵营划分
【看多派】大师A、大师B
【看空派】大师C

### 辩论实录
💬 第一只：贵州茅台（35%）
[大师A]：...
[大师C]：...
[大师A]：...

💬 第二只：宁德时代（20%）
...

### 主持人总结
**核心共识**：...
**最大分歧**：...
**带走的思考**：...
```

---

## Step 5 · 风控团队审核

### 5.1 三方视角

**激进派**：
- 强调收益机会
- 建议加仓方向
- 关注成长性

**中性派**：
- 平衡风险收益
- 建议持有
- 关注仓位结构

**保守派**：
- 强调下行风险
- 建议减仓/止损
- 关注防御性

### 5.2 输出格式

```
## ⚠️ 风控审核

### 激进派观点
...

### 中性派观点
...

### 保守派观点
...

### 最终建议
[综合三方意见，给出具体建议]
```

```
[Step 1 输出]
```

---

## 关键纪律

1. **信息不丢失**：每一步的输出都存入全局状态，后续步骤可查询
2. **推理透明**：展示每一步思考过程（ReAct）
3. **真实辩论**：不强行调和，忠实呈现分歧
4. **风控前置**：决策前先过风控
5. **全程留痕**：每个环节都有记录，可追溯
