# ReAct推理模板

> 每位大师在分析时，遵循"思考→行动→观察→判断"的循环。
> 推理过程透明可见，用户能看到大师是怎么一步步得出结论的。

---

## ReAct循环结构

```
【思考】大师提出问题
【行动】大师查询数据/调用工具
【观察】大师获取结果
【判断】大师得出结论
```

---

## 独门论股ReAct示例（巴菲特分析茅台）

```
## 🥋 巴菲特·独门论股

### 推理过程

【思考】茅台的护城河是什么？我需要了解它的品牌价值和市场地位。

【行动】查询茅台的品牌价值排名、市场份额、定价历史。

【观察】
- 品牌价值全球第32位，中国白酒第一
- 市场份额60%+，高端白酒绝对龙头
- 过去10年持续提价，定价权强

【判断】茅台有持久护城河——品牌+定价权+网络效应。符合第一条标准。

---

【思考】茅台的ROE和自由现金流如何？我需要看财务数据。

【行动】查询茅台近5年ROE、资本开支、自由现金流。

【观察】
- ROE持续30%+，远高于15%标准
- 资本开支低，不需要大量再投资
- 自由现金流充沛，每年500亿+

【判断】ROE和现金流都符合"伟大公司"标准。

---

【思考】茅台的估值是否合理？我需要对比历史PE和同行业。

【行动】查询茅台历史PE区间、同行业PE。

【观察】
- 当前PE 30x，处于历史中位数
- 同行业高端白酒PE 25-35x，茅台处于合理区间

【判断】以合理价格买入伟大公司——符合我的原则。

---

【思考】35%仓位是否太重？我需要从风险角度思考。

【行动】逆向思考：什么情况下茅台会让我血本无归？

【观察】
- 反腐再来一轮？可能，但茅台已经经历过，恢复能力强
- 年轻人不喝白酒？趋势存在，但高端白酒社交属性强
- 估值从30x掉到10x？极端情况，但基本面不变

【判断】如果真看懂了茅台，35%仓位合理。但前提是裸股、不带杠杆。

---

### 最终判断

茅台符合"伟大公司"标准：持久护城河、高ROE、充沛现金流、合理估值。
35%仓位在裸股+真看懂的前提下可以接受。
```

## 群雄论股ReAct示例（多大师辩论宁德时代）

```
## 🎙️ 群雄论股·宁德时代辩论

### 推理过程

【思考】芒格：宁德这种公司我最不想碰——我需要看它的自由现金流。

【行动】查询宁德近3年净利润、资本开支、自由现金流。

【观察】
- 净利润100亿
- 资本开支200亿
- 自由现金流-100亿（负值）

【判断】这不是生意，是融资黑洞。账面利润全部砸进新厂。不碰。

---

【思考】段永平：芒格说得对，但我需要从"看懂"角度思考。

【行动】思考：我能说清五年后宁德为什么还能赢吗？

【观察】
- 技术变革太快，今天的护城河明天可能被填平
- 行业内卷，比亚迪、特斯拉都在做电池
- 政策变化风险大

【判断】我看不清五年后宁德还能赢。进不了我的20个打孔位。

---

【思考】散户乙：我从树论角度看——宁德这棵树分不分红？

【行动】查询宁德分红历史。

【观察】
- 宁德不分红
- 所有利润拿去再投资

【判断】这棵树不分红，把所有利润拿去种新树。新树可能结果，也可能死掉。
这不是我的树，我不会拿。

---

### 辩论总结

【芒格】自由现金流为负 → 不碰
【段永平】看不清五年后 → 不进打孔位
【散户乙】不分红 → 不是树

三方一致：宁德时代不该重仓。
```

## ReAct模板格式

每位大师输出时，按以下格式：

```
### 推理过程

【思考】[大师提出的问题]

【行动】[大师查询的数据/调用的工具]

【观察】[大师获取的结果]

【判断】[大师得出的结论]

---

（重复上述循环，直到得出最终判断）

---

### 最终判断

[大师的综合结论]
```

## 使用说明

1. **独门论股**：大师内部多轮ReAct循环，最后给出综合判断
2. **群雄论股**：每位大师独立ReAct，然后互相辩论
3. **展示给用户**：推理过程完整展示，让用户看到"大师是怎么思考的"
